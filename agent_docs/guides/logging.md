# Стандарты логирования

## Когда логировать

Скрипт CLI — логирование минимальное:
- JSON на stdout: результат операции
- Диагностика на stderr: создание аккаунта, предупреждения

## Формат

Stdout (для машинного чтения):
```json
{"ok": true, "url": "https://telegra.ph/...", "path": "..."}
```

Stderr (для человека):
```json
{"event": "account_created", "short_name": "claude_code"}
```

## Правила

- Минимум данных — только то, что нужно вызывающему
- Ошибки — JSON с `"ok": false` и `"error": "описание"`
- Не логировать контент пользователя
- Не логировать токены
