# Архивация и временные файлы

## Архивация

При замене важных файлов:
1. Создать `archive/`
2. Имя: `[YYYY-MM-DD_HH-MM]_original_name.ext`
3. Добавить префикс с датой, причиной, ссылкой на новую версию
4. Переместить в archive/

Не архивировать: временные файлы, git-файлы, секреты, большие бинарники.

## Временные файлы

- Хранить в `temp/` в корне репо
- Очищать после завершения задачи
- Добавить в .gitignore
