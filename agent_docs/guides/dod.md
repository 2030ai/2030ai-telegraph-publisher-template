# Definition of Done

## Минимум

- [ ] Функциональность работает
- [ ] Тесты проходят (или задокументирована причина их отсутствия)
- [ ] Документация обновлена, включая development-history.md

## По типу задачи

### Новая фича
- [ ] Обновить skill.md если затрагивает CLI-интерфейс
- [ ] Обновить AGENTS.md если меняются conventions
- [ ] Добавить тесты в test_publish.py

### Баг-фикс
- [ ] Найдена root cause
- [ ] Добавлен regression-тест
- [ ] Проверено: не сломаны существующие тесты

### Рефакторинг
- [ ] Функциональность не изменилась (тесты подтверждают)
- [ ] ADR создан, если изменение значительное

### Документация
- [ ] Информация актуальна
- [ ] Примеры кода включены
- [ ] Ссылки проверены
