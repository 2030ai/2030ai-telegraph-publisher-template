## ADR-001: Stdlib only, zero dependencies

**Статус:** Принято

**Контекст:** Скрипт устанавливается в `~/.claude/` и должен работать на любой машине с Python 3.10+. Зависимости от pip-пакетов создают friction при установке.

**Решение:** Использовать только стандартную библиотеку Python (urllib, html.parser, json, argparse).

**Обоснование:** Claude Code skill должен быть plug-and-play. Один файл, никаких `pip install`.

**Последствия:** Markdown-конвертер реализован через regex (не полный CommonMark). HTML-парсер — через html.parser (не lxml/BeautifulSoup). Это ограничивает edge cases, но покрывает 95% реального использования.

## ADR-002: Таблицы как моноширинный <pre>

**Статус:** Принято

**Контекст:** Telegraph API не поддерживает `<table>`. Ранее таблицы просто игнорировались.

**Решение:** Рендерить HTML `<table>` и Markdown pipe-таблицы как `<pre>` блоки с Unicode box-drawing символами (┌─┬─┐).

**Обоснование:** Моноширинный текст в `<pre>` — единственный способ показать табличные данные с выравниванием на Telegraph.

**Альтернативы:** Скриншоты таблиц (сложнее автоматизировать), CSV-текст (нечитаемо).

## ADR-003: Auto-split контента > 64KB

**Статус:** Принято

**Контекст:** Telegraph ограничивает контент 64KB на страницу. Раньше скрипт возвращал ошибку.

**Решение:** Автоматически разбивать на части с навигационными ссылками «← Часть 1 · Часть 3 →».

**Обоснование:** Для агента естественнее получить результат, чем ошибку. Пользователь получает связанные страницы с навигацией.

**Последствия:** Для `edit` — при разбиении создаются дополнительные страницы, которые не удалятся при повторном редактировании с меньшим контентом.
