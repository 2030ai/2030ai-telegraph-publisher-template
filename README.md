# Telegraph Publisher

Скилл для [Claude Code](https://docs.anthropic.com/en/docs/claude-code), который публикует контент на [telegra.ph](https://telegra.ph) и возвращает ссылку.

Агент сгенерировал длинный анализ, таблицу сравнений или разбор — а поделиться можно только копипастой? Этот скилл решает проблему: одна команда — и результат доступен по ссылке.

**Что умеет:**
- Принимает HTML, Markdown и plain text
- Таблицы рендерит красиво — моноширинным текстом с рамками
- Загружает изображения на Telegraph CDN
- Большой контент (>64KB) автоматически разбивает на связанные страницы
- Аккаунт Telegraph создаётся автоматически при первом использовании

**Без зависимостей.** Один файл на Python, только стандартная библиотека.

## Установка

Вставьте этот промпт в Claude Code / Codex:

> Скачай файлы из репозитория github.com/2030ai/2030ai-telegraph-publisher-template: файл `publish.py` сохрани в `~/.claude/telegraph/publish.py`, а skill manifest `.agents/skills/telegraph/SKILL.md` сохрани как canonical source в `.agents/skills/telegraph/SKILL.md` текущего проекта. Создай symlink mirrors: `.claude/skills/telegraph`, `.codex/skills/telegraph`, `.cursor/skills/telegraph` → `../../.agents/skills/telegraph`.

После этого скилл готов к работе. Токен Telegraph создастся автоматически при первой публикации.

## Как пользоваться

Просто напишите в Claude Code одну из фраз:

- «опубликуй на телеграф»
- «publish to telegraph»
- «сделай ссылку на telegra.ph»

Claude сам отформатирует контент и вернёт ссылку.

### Примеры

**Опубликовать результат анализа:**
> Проанализируй этот файл и опубликуй результат на телеграф

**Опубликовать содержимое файла:**
> Опубликуй содержимое report.md на telegraph

**Отредактировать страницу:**
> Обнови страницу telegra.ph/My-Page-03-08 — добавь раздел с выводами

**Посмотреть список страниц:**
> Покажи мои страницы на telegraph

**Загрузить картинку:**
> Загрузи screenshot.png на telegraph и вставь в статью

## Поддерживаемые форматы

| Формат | Когда используется |
|--------|-------------------|
| Markdown | По умолчанию для генерируемого контента — статьи, отчёты, заметки |
| HTML | Когда нужен точный контроль над разметкой |
| Text | Простой текст без форматирования |

Формат определяется автоматически по расширению файла (`.md`, `.html`, `.txt`).

## Что происходит с контентом

Telegraph поддерживает ограниченный набор HTML-тегов. Скрипт автоматически преобразует контент:

- `h1`, `h2` → `h3` (Telegraph не поддерживает крупные заголовки)
- `h5`, `h6` → `h4`
- `<table>` → моноширинный `<pre>` блок с рамками из Unicode-символов
- `<div>`, `<span>`, `<section>` → содержимое сохраняется, обёртка убирается
- Жирный, курсив, ссылки, списки, цитаты, код — всё работает

## Токен

Хранится рядом с `publish.py`. При установке по инструкции выше это `~/.claude/telegraph/token.txt`. Создаётся автоматически при первом запуске.

Если хотите использовать свой токен, задайте переменную окружения:

```bash
export TELEGRAPH_ACCESS_TOKEN=ваш_токен
```

## Ограничения

- Контент до 64KB на страницу (при превышении — автоматическое разбиение на части)
- Страницы нельзя удалить, только отредактировать
- Нет поддержки вложенных таблиц
